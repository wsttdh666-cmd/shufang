# 书房

一个自用的安卓 App：搜书、书架、把小说做成酒馆（SillyTavern）角色卡和世界书。

## 安装和更新

1. 到 [Releases](https://github.com/wsttdh666-cmd/shufang/releases/latest) 下载 `shufang.apk`，点开安装。
2. 以后更新：App 里「密钥」页最下面点「检查更新」，有新版会直接下载安装，不用卸载旧版。

## 五个标签

- **搜书**：在网盘公开分享里找书。
- **导书**：粘贴起点、晋江、番茄或刺猬猫的作品详情链接，按目录收集公开网页直接提供的章节文字，保存到书架并下载 TXT。可在当次导入中暂停、继续或只保存已读章节。验证页、专用字体和仅供试读的章节会提示原因。
- **书架**：导入、保存、导出 txt。书存在 App 里，卸载会一起删掉。
- **制卡**：从书架选一本书，生成角色卡 PNG 和带蓝绿灯的世界书 JSON。
- **密钥**：模型接口、搜索服务地址。只保存在这台手机上。

## 说明

- 仅供个人使用。导出的书和做出来的卡不要对外传播。
- 安装包只从本仓库的 Releases 下载。本仓库的签名钥匙是公开的，别人转发的安装包可能被改过。
- 外壳和更新方式沿用自 [yjqiandao](https://github.com/wsttdh666-cmd/yjqiandao)。
